# Hanie OS

Interactive OS-inspired portfolio for a Frontend Engineer.

## Stack

- Next.js (App Router)
- TypeScript
- React
- Tailwind CSS
- Motion

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — production server
- `npm run lint` — ESLint
